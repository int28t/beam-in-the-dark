# Публикация Beam in the Dark 0.9.0

Самый короткий путь: GitHub Pages → проверка на телефоне → кнопка запуска в Telegram. Для текущей игры не нужны VPS, база данных, npm, webhook или постоянно работающая программа бота. Публикация и настройка BotFather выполняются владельцем; агент сделал только локальные коммиты, без push.

## 1. Быстро проверить на телефоне до публикации

На Mac из папки проекта:

```sh
python3 -m http.server 8000 --bind 0.0.0.0
```

Телефон и Mac должны находиться в одной доверенной Wi-Fi-сети. Посмотри локальный IP компьютера в настройках Wi-Fi или командой `ipconfig getifaddr en0` (если интерфейс другой, смотри настройки сети). Открой на телефоне `http://IP-КОМПЬЮТЕРА:8000/`.

`localhost` на телефоне указывает на сам телефон. Если страница не открывается, проверь одинаковую сеть, запрет связи между устройствами в гостевом Wi-Fi и разрешение локального сервера в брандмауэре. После проверки останови сервер через Ctrl+C. Сервер раздаёт папку проекта: используй этот способ только в доверенной локальной сети. Для Telegram далее понадобится публичный HTTPS-адрес.

## 2. Опубликовать отдельную ветку, сохранив dev локальной

Твой origin: [int28t/beam-in-the-dark](https://github.com/int28t/beam-in-the-dark).

Сначала убедись, что локальные изменения закоммичены и проверки проходят:

```sh
git status --short
node tests/run.js
```

Если `git status` вывел несохранённые изменения, сначала разберись с ними. Для первой публикации создай отдельную ветку `pages` от текущего проверенного `dev`:

```sh
git branch pages dev
git push -u origin pages
```

**Эти команды выполняешь ты.** Push публикует `pages`, а не `dev`. Если ветка `pages` уже существует, не пересоздавай её: смотри раздел обновления ниже.

Затем в GitHub:

1. Открой [Settings → Pages](https://github.com/int28t/beam-in-the-dark/settings/pages).
2. В **Build and deployment → Source** выбери **Deploy from a branch**.
3. Выбери ветку **pages** и папку **/(root)**, нажми **Save**.
4. Дождись успешного задания Pages в разделе **Actions**. На странице Pages появится опубликованный адрес; если публикация не завершилась, смотри лог задания.
5. Ожидаемый адрес при стандартных настройках — `https://int28t.github.io/beam-in-the-dark/`. Используй фактический URL из Pages, если настроен другой домен.

В корне есть `.nojekyll`: сайт статический, отдельной сборки нет. Игнорируемая папка `temp/` не попадёт в ветку, если её специально не добавлять принудительно.

На GitHub Free Pages доступен для публичных репозиториев; возможность Pages для приватного репозитория зависит от тарифа. Если пункт недоступен, проверь видимость и тариф, а не меняй их автоматически. [Официальная настройка источника Pages](https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site).

## 3. Проверить опубликованную игру на телефоне

Открой HTTPS-ссылку в Safari/Chrome. Игра должна показывать версию **0.9.0**.

- Начни игру: левый джойстик двигает героя; кнопка «Фонарь» переключает свет; пауза находится сверху.
- В паузе выбери **Прицеливание → Правый джойстик**. Правый стик задаёт направление света; после отпускания направление сохраняется, левым можно отходить назад. Вариант **По движению** остаётся доступен.
- По умолчанию **Качество → Авто** выбирает экономный режим на сенсорном устройстве. **Экономное**: pixel ratio не выше 1, тени 512, меньше декора. **Обычное**: pixel ratio не выше 1.5, тени 1024. Коллизии, карта и сложность не меняются.
- Поверни телефон, отпусти оба пальца, сверни и верни браузер. Движение должно остановиться; после возврата нажми «Продолжить».
- Проверь ключ, батарейку, свет на врага, поражение, повтор и следующий этаж. Попробуй одновременно двигаться одним пальцем, направлять свет другим и переключать фонарь.
- После нескольких секунд игры зайди в паузу: там виден последний замер кадров/с. Запиши модель телефона, ОС, браузер, код этажа и качество. Ориентир для тяжёлого этажа — стабильные 30 FPS в экономном режиме; это цель проверки, а не уже подтверждённая производительность.
- Перезагрузи страницу: рекорд, звук, качество и режим прицеливания должны сохраниться. Браузер и Telegram могут иметь разные локальные хранилища, поэтому рекорд между ними не обязан совпадать.

Если видна старая версия, дождись завершения Pages и перезагрузи страницу/закрой старое окно игры. Если кэш ещё старый, подожди его обновления или выполни полную перезагрузку/очистку кэша сайта; один параметр в адресе не обновляет автоматически все JS-модули. При ошибке загрузки проверь доступ к `cdn.jsdelivr.net`; Telegram SDK необязателен для обычного браузера. Импорт модулей проверяется по `/tests/index.html` на том же сайте.

## 4. Подключить Telegram

Открой официального [@BotFather](https://t.me/BotFather).

1. Если бота нет, отправь `/newbot`, задай имя и свободный username, заканчивающийся на `bot`. Для текущего клиентского приложения выданный токен нигде в коде не нужен; не добавляй его в репозиторий или URL.
2. Отправь `/setmenubutton`, выбери бота и укажи **полный HTTPS URL игры** из GitHub Pages. Задай текст кнопки, например «Играть». Альтернатива в меню BotFather: **Bot Settings → Menu Button**. [Официальная настройка кнопки](https://core.telegram.org/bots/webapps#launching-mini-apps-from-the-menu-button).
3. Открой личный чат с ботом, нажми Start при необходимости, затем кнопку «Играть». Отдельный обработчик `/start` для такого запуска не требуется: мы настраиваем кнопку приложения, а не текстовые ответы бота.
4. Дополнительно настрой **Main Mini App** в BotFather, указав тот же URL. После этого будет доступна кнопка запуска в профиле и ссылка вида `https://t.me/USERNAME_БОТА?startapp`. Одной настройки Menu Button для этой ссылки недостаточно. [Main Mini App](https://core.telegram.org/bots/webapps#launching-the-main-mini-app).

Внутри Telegram игра вызывает ready/expand, учитывает безопасную область и ставит игру на паузу при деактивации. На поддерживаемых клиентах доступен отдельный запрос полного экрана и короткие вибрации. Полный экран не обязателен. Пользовательские данные и токен бота игра не отправляет на собственный сервер; сервера у этой версии нет.

Для новых возможностей нужны соответствующие версии клиента: haptics — API 6.1+, управление вертикальными жестами — 7.7+, fullscreen/safe areas — 8.0+. Неподдерживаемые методы пропускаются. В меню вертикальные жесты возвращаются к исходному состоянию; во время игры они отключаются при поддержке, чтобы не мешать стикам. [SDK и возможности клиента](https://core.telegram.org/bots/webapps#initializing-mini-apps).

Проверь отдельно реальный Telegram на iOS и Android: оба стика, кнопку фонаря, поворот, сворачивание, safe areas, звук после нажатия «Войти», fullscreen и отсутствие ошибок при его отказе. Простое открытие HTTPS-страницы в браузере не подтверждает интеграцию Telegram.

## 5. Как обновлять игру

После следующих локальных коммитов в `dev` и проверок:

```sh
git switch pages
git merge --ff-only dev
git push origin pages
git switch dev
```

Сначала `git status --short` должен быть чистым. `--ff-only` не переписывает историю: если Git отказался, остановись и разберись с расхождением, не делай force push. В Pages должна оставаться выбрана ветка `pages`; публикация обновится после успешного задания. URL в BotFather менять не требуется.

Перед обновлением запиши hash текущей опубликованной версии (`git rev-parse pages`). Для отката выбери отдельную ветку от этого сохранённого коммита и переключи источник Pages на неё; это не требует переписывать существующую историю.

## Текущий статус

Код 0.9.0 и автоматические проверки готовы. Публикация, создание/настройка бота, реальные iOS/Android, WebGL-консоль и замеры на телефоне не выполнены агентом: у него нет доступного браузерного/устройственного управления. Успешные тесты адаптеров не заменяют эти шаги.
